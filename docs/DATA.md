# 内容、图片和运行数据

演示快照来自原本地 WordPress 已填写的内容。首页、产品、类目、行业、页面、文章、菜单、字段值、模板选择、分类关系和作者示例一并保留。图片使用原媒体和 WordPress 生成的各尺寸文件，文件指纹见 `site/media-manifest.json`。

快照没有原站用户表、密码、会话、应用密码、SMTP / 企业邮箱、主机资料、插件授权密钥、历史询盘或邮件记录。原来的修订历史和临时编辑锁不属于演示种子。新的管理员和示例作者在首次启动时重新创建。

## 两种数据

`site/content.json` 与 `site/uploads/` 提供第一次打开时的完整内容。第一次启动后，当前站点的数据库和后续媒体保存在 `.runtime/wordpress/wp-content/` 下。SQLite 数据库由 Playground 创建；不要在运行中手工改写数据库文件。

后台编辑后再停止、启动，修改仍然保留。每个克隆文件夹有自己的 `.runtime/`，不会覆盖其他用户或原站。端口变化时，启动程序只调整本地地址引用，保留内容。

## 备份、换电脑和恢复

1. 在运行终端按 Ctrl+C，等待站点停止。
2. 备份整个 `.runtime/`，同时保留相同版本的仓库源码与依赖锁文件。新询盘附件在 `.runtime/private/`，备份时一起带上。
3. 换电脑时把这份 `.runtime/` 放回同一项目相对位置，再启动；不要用初始内容重新导入。

运行目录含你后来在本机填写的数据和登录资料，备份应私下保存，不应提交到公开仓库。

需要恢复到最初演示时，先停机，把 `.runtime/` **重命名为备份目录**（例如 `.backups/runtime-before-reset/`），然后重新启动。不要在不确认后续修改是否需要保留的情况下删除运行目录。原备份仍可恢复。

## 表单与附件

演示表单使用 Fluent Forms，本地 Entries 可以查看记录。允许的附件类型与大小由业务插件保持，附件放在网站目录以外，通过已登录且获授权的后台入口下载。匿名不能直接获取私有文件。

本地演示没有真实邮件投递。插件内部的“邮件处理成功”仅表示本地拦截器完成处理，不能证明任何收件箱收到了邮件。测试表单请使用示例资料。
