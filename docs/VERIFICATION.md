## 打包时修复的独立环境问题

1. 新建演示用户补齐 WordPress 原生富文本编辑默认值，保证 Visual / Text 均可使用。
2. 从内容快照迁移后，使用插件自身安装接口创建空的 SEO 缓存 / 重定向及私有附件工作表，未复制原业务日志或历史询盘。
3. 本地 HTTP 入口阻止隐藏文件、数据库及私有路径访问，并限制本机地址。
4. Fluent Forms 日期筛选发送的 `2026/9/21` 等日期，在本地隔离插件中转换为 SQLite 存储使用的 `2026-09-21`；保留原插件源码与权限检查。原生后台列表已实际显示测试记录。
5. 启动入口使用当前进程的可用通用 locale，避免某些父应用传入未安装的 locale 导致校验工具退出；不改变系统设置。
